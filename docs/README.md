# NorAI Technologies Frontend Documentation

## Project Overview
Welcome to the NorAI Frontend Documentation repository. This is the single source of truth for the strategic, visual, and architectural implementation of the NorAI Technologies website. It bridges the gap between our premium, enterprise-ready brand vision and the technical execution required to build a world-class AI product web presence.

## Documentation Hierarchy
The documentation is organized into clear, focused directories:

- **[`design/`](./design/)**: The core design specifications. Contains the Design Bible and Masterplan.
- **[`implementation/`](./implementation/)**: The rules of execution. Workflows, roadmaps, and guidelines for both human and AI contributors.
- **[`architecture/`](./architecture/)**: The technical structure. Documentation on routing, component hierarchies, and tokens.
- **[`decisions/`](./decisions/)**: Architecture Decision Records (ADRs). Historical context on why major technical and UX choices were made.
- **[`assets/`](./assets/)**: Diagrams, screenshots, and visual references.
